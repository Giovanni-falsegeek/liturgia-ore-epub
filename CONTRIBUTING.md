# Contribuire

Apri una segnalazione descrivendo comando, data, ora, versione di Python ed errore.
Non pubblicare HTML CEI, testi liturgici, cache, ePub o informazioni personali.
Per riprodurre un problema usa dati inventati con la struttura necessaria.

Prima di proporre modifiche esegui `python -m unittest discover -s tests -v`.
Mantieni la compatibilità con Python 3.9 e la sola libreria standard.
